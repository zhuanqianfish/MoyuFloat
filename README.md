加几盏灯，拖一拖，一张平面的画就有了舞台感。

## ✨ 功能亮点

| | 功能 | 说明 |
|---|---|---|
| 🖼️ | **一键导入** | 拖拽或选择本地图片，秒开预览 |
| 🧠 | **AI 深度生成** | 内置 Depth Anything V2-small，浏览器本地推理（WebGPU 优先，自动回退 WASM），模型权重缓存后离线可用 |
| 🎚️ | **深度视差** | 移动鼠标视角，前景 / 背景按深度自然错动 |
| 💡 | **法线光照** | 深度图转法线贴图，动态光影实时响应 |
| 🔦 | **多灯光舞台** | 可添加多盏彩色灯光，拖拽布光，调颜色、强度、范围 |
| 🖌️ | **深度画笔** | AI 估不准的地方，手动涂抹修正 |
| 🌓 | **深度反转** | 一键切换远近关系，适配不同深度图约定 |
| 📥 | **一键导出** | 把渲染结果导出为 PNG |

## 🛠️ 技术栈

- **Three.js / WebGL** —— 实时 3D 渲染（视差 + Phong 光照着色器）
- **Transformers.js** —— 浏览器端 AI 推理运行时
- **Depth Anything V2** —— 单目深度估计
- **Canvas 2D** —— 深度 / 法线预处理（Sobel 算子）
- **零构建** —— 整个应用就是一个 `index.html`，无打包、无服务端

## 🚀 快速开始

```bash
git clone https://github.com/zhuanqianfish/MoyuFloat.git
cd MoyuFloat
# 直接用现代浏览器打开 index.html 即可
```

也可以部署到任何静态托管：GitHub Pages / Cloudflare Pages / Vercel / Netlify。

## 🖱️ 使用指南

1. **上传图片** —— 把 2D 插画拖进来（示例场景可直接体验）
2. **生成深度** —— 点 `AI 生成深度`（首次需联网下载模型，之后缓存离线可用）；
   也可以上传自己的深度图、用亮度启发式生成，或拿画笔手涂
3. **玩光影** —— 移动鼠标感受视差 → 添加灯光 → 拖到想要的位置 → 调颜色和强度
4. **导出** —— 满意后导出 PNG

> 小贴士：前后关系明确的人物、插画，AI 深度效果最好；深度不准就用画笔涂两下。

## 🔒 隐私说明

所有 AI 推理与渲染都在**本地浏览器**完成，图片不会上传到任何服务器。
（首次 AI 推理需联网下载模型权重，之后可离线使用。）
